# 🥤 Coca-Cola Landing Page

A modern and visually attractive **Coca-Cola Product Landing Page** built with a clean dark theme, bold typography, and smooth premium-style UI inspired by modern beverage brand websites.

---

## ✨ Preview

A stylish homepage featuring:

* Hero section with bold marketing headline
* Coca-Cola product showcase
* Premium dark UI with red accent theme
* Product information section
* Responsive navigation bar
* Elegant CTA button (Taste Now)
* Modern branding-focused layout
